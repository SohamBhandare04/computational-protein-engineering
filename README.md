# Computational Protein Engineering — O₂ Tunnel Analysis in Hydroxylases

Undergraduate research project investigating oxygen transport tunnels 
in hydroxylase proteins using computational and ML-based approaches.

## Research context

- **Institution:** IIT Mandi, BSc Chemical Sciences
- **Supervisor:** Prof. Bhaskar Mondal
- **Focus:** Predicting and engineering O₂ transport tunnels in 
  hydroxylase proteins for biocatalytic applications
- **Status:** Active — ongoing (Aug 2026)

## Approach

- Protein tunnel detection and geometry analysis using CAVER
- Molecular dynamics trajectory analysis using MDAnalysis
- Protein structure prediction and visualization via ColabFold and PyMOL
- ML-based tunnel property prediction (in development — ProTunnelML)
